# Résultat pulsatile

Données entièrement simulées.

- profiles.gif : cycle animé, observations affichées seulement à leurs phases.
- spacetime.png : référence, reconstruction et erreur ; zone temporelle cachée indiquée.
- comparison.png : profils, apprentissage, débit et cisaillement.
- metrics.json : erreurs, réglages et temps de calcul.
- model.pt : poids sauvegardés ; aucun rechargement automatique au prochain lancement.
- observations.json et predictions.npz : données numériques reproductibles.

Le forçage et l'équation sont connus partout. Ce résultat teste une reconstruction
dans un régime périodique, pas une prédiction d'un futur inconnu.
